Language Tutorial & Syntax Guide

Learn how to write scripts in your custom-built programming language:

  • Assignment (>): Assigns a value or expression result to a variable. Example: 4>P sets variable P to 4.
  • Sequential Chaining (:): Separates individual commands or steps in a sequence.
  • Conditionals (:VAR;VAL): Checks if a variable equals a target value. Example: :S;1 checks if S == 1.
  • Negation / Else-Not (;/;): Checks if a variable does not equal a target value. Example: :S;/;1 triggers if S != 1.
  • Loop Blocks ([...] > D!): Wraps a block of code in brackets and repeats it D times using the exclamation mark modifier.

Sample Leibniz Pi Script Breakdown:

4>P:3>B:1>S:1000>D:  [ ... ] : D! > C

│       │ │    │      │     │  └── Stores final result in C
│       │ │    │      │     └──── Loops D times (1000 iterations)
│       │ │    │      └────────── Code block containing if/else conditional math
│       │ │    └───────────────── Sets loop counter D = 1000
│       │ └────────────────────── Sets toggle state S = 1
│       └──────────────────────── Sets denominator B = 3
└──────────────────────────────── Sets starting Pi approximation P = 4
