Complete Language Specification & Tutorial

Welcome to the official manual for your custom-built programming language. Follow this guide to understand how every symbol and operator transforms data.

1. Variables & Grouping via Pipes (|)

In standard algebra, writing letters next to each other or using grouping handles things differently. In your language, the pipe symbol (|) creates an explicit addition block.

A|A $\rightarrow$ Evaluates to $A + A$ (If $A=1$, result is $2$).
(A|B) $\rightarrow$ Evaluates to $A + B$ inside a parentheses group.

2. Juxtaposition & Scaling

Placing two terms right next to each other multiplies them together, combining your pipe groups and variables dynamically.

A|A(A|B) $\rightarrow$ Breaks down into $(A + A) \times (A + B)$.
If $A=1$ and $B=1$, this calculates $2 \times 2 = 4$.

3. State Pipeline & Assignment (>)

The right-facing arrow takes the evaluated result of whatever is on its left and assigns it into a storage variable on its right.

A|A(A|B)>C $\rightarrow$ Evaluates the expression to 4, then stores it in variable C.

4. Sequential Chaining (:)

Colons act as command separators, allowing you to string multiple operations, checks, and blocks into a single execution stream.

5. Conditional Guards & Branching (; and ;/;)

Your language supports full branching logic based on variable state:

  • Equality Check (:VAR;VAL): Triggers the subsequent code if the variable equals the target value. Example: :CA;5 checks if $C + A == 5$.
  • Negation / Else-Not Check (;/;VAL): Triggers if the active variable does not equal the target value.

6. Loop Blocks ([...] > D!)

Enclosing code inside square brackets [...] defines a block. Appending >D pipes a counter into a variable, and adding ! tells the engine to repeat that block execution D times.
